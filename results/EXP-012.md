# EXP-012 — Can Qwen read known text regions?

**Completed 25 September 2026 · READ2016 · Qwen3-VL-4B-Instruct · random seed 824**

## Why and how

Earlier experiments asked a model to transcribe a whole historical page. This experiment checks a simpler, separate OCR task: **given READ2016's existing text-line boxes, can Qwen transcribe each cropped line and return the page's text in reading order?** The model predicts words, not box positions. Each entire TRAIN page is still the unit selected for annotation.

The untouched model first read the 42-page validation slice before any training. Three fixed rounds then added 64 randomly selected TRAIN pages each. The source's true transcripts simulated a human annotator for those selected pages. At every round, a fresh LoRA adapter was trained from the same original Qwen model on all selected lines so far (64, 128, then 192 pages). Fitting and inference used Modal L4. The study stopped after three rounds; validation scores did not decide when to stop.

**CER** is character edits divided by reference characters, and **WER** is word edits divided by reference words. Lower is better; values above 1 are possible when a model inserts much extra text. All four checkpoints used the same 42 official validation pages (861 supplied line regions, 17,718 reference characters, 2,675 words). Capped/empty region outputs counted as empty predictions.

| TRAIN pages labelled | Line crops trained | CER ↓ | WER ↓ | Capped regions |
| ---: | ---: | ---: | ---: | ---: |
| 0 — original model | 0 | 0.804 | 1.087 | 2/861 |
| 64 | 1,537 | 0.190 | 0.581 | 0/861 |
| 128 | 3,037 | 0.123 | 0.452 | 0/861 |
| 192 | 4,567 | **0.094** | **0.370** | 0/861 |

## What the result means

The original model struggled with these historical line crops. After 64 labelled pages, character error fell sharply; it continued to fall as the selected set grew to 192 pages. Relative to the original model, CER fell by **88.3%** at the final checkpoint. The final WER of 0.370 still means substantial word-level errors remain, even with known locations.

This is a **working random-selection learning curve for recognition with provided boxes**. It does not show that an active-learning selector improves on random, because no model-guided selector was run in EXP-012. It does not test line detection or claim a fair accuracy comparison with whole-page EXP-009–011: the input and training recipe differ. This is one random seed on official validation, with unknown document grouping and possible base-model pretraining overlap; no independent final test was used.
