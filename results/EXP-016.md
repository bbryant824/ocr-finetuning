# EXP-016 — What do random OCR examples actually help with?

**Approved study in progress; no EXP-016 GPU results yet.**

EXP-015 found modest OCR gains from examples and a large reduction in unexpected Cyrillic
outputs, while fine-tuning on the same available labels remained substantially stronger.
EXP-016 tests whether the useful signal requires a correct crop/transcript association.

We compare correct paired examples with the same transcripts alone and with deliberately
mismatched crop/transcript pairs. The query crop stays present in every condition. Qwen3-VL-4B,
READ2016 supplied line boxes, the exact 24-page/589-line TRAIN bank, seed 824, 8/24 shots and
penalty 1.1 remain fixed. No model is trained.

Verify a small L4 replay, then all 182 VAL8 lines before running the same 861 VAL42 lines as
EXP-015. Reuse verified zero-shot, paired ICL and EXP-013 random LoRA24 predictions; recompute
all scores. Primary CER/WER scores every raw line including capped repetitions; historical
page scores and caps are secondary. Pilot outcomes do not choose full-run conditions.

Methods, reproduction and exact evidence locations: [technical record](../experiments/EXP-016.md).
Final findings will replace this status paragraph after verification. Historical evidence is preserved.
