# EXP-011 — Which pages should Qwen learn from?

**Seed-824 pilots complete for visual diversity, entropy and least confidence; paired repeat seeds are in progress.** We compare ways to choose the next READ2016 TRAIN pages for Qwen3-VL-4B whole-page transcription. Every path starts from the same untouched base model and first 64 randomly selected pages. At each later round it selects 64 new pages, reveals only their true TRAIN transcripts to simulate annotation, then trains a fresh adapter from the same base model on all 128 or 192 selected pages. Training and evaluation settings are fixed.

K-center chooses pages that expand coverage in frozen Qwen visual-feature space. Entropy chooses pages with the highest mean next-token uncertainty along their generated text. Least confidence chooses pages whose generated text has the lowest length-normalized probability under the current adapter. Random selection is the matched control. All saved checkpoints were evaluated on the same 42 official validation pages. **CER** is character edits per reference character and **WER** is word edits per reference word; lower is better. Outputs cut off by the fixed token cap count as empty predictions.

| Labelled TRAIN pages | Random CER / WER ↓ | K-center CER / WER ↓ | Entropy CER / WER ↓ | Least-confidence CER / WER ↓ | Truncated: random / k-center / entropy / confidence |
| ---: | ---: | ---: | ---: | ---: | ---: |
| 0 | 0.7902 / 1.0019 | same checkpoint | same checkpoint | same checkpoint | 10 / 10 / 10 / 10 |
| 64 | 0.5025 / 0.8643 | same checkpoint | same checkpoint | same checkpoint | 3 / 3 / 3 / 3 |
| 128 | 0.2946 / 0.6841 | 0.3113 / 0.6976 | 0.2766 / 0.6770 | 0.2825 / 0.6781 | 1 / 1 / 0 / 0 |
| 192 | 0.2112 / 0.5589 | 0.1994 / 0.5574 | 0.1934 / 0.5409 | 0.1930 / 0.5473 | 0 / 0 / 1 / 0 |

**The single-seed result is mixed.** K-center was worse than random at 128 pages, then lowered CER by 0.0118 at 192 pages while WER barely changed. Entropy and least confidence lowered both CER and WER at both budgets; their 192-page CER improvements versus random were 0.0178 and 0.0182. The 128-page random run truncated one validation page while both uncertainty methods truncated none; at 192 pages entropy truncated one while random and least confidence truncated none. These differences do not establish a repeatable advantage. Paired runs with seeds 825 and 826 are still needed. Uncertainty scoring also took much longer than frozen visual-feature extraction; exact observed spans are in the technical record.

These are **official validation** results, not a document-independent final TEST result. Document grouping and possible model-pretraining overlap are unknown. Equal page counts also do not measure human annotation time.
