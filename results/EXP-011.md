# EXP-011 — Which pages should Qwen learn from?

**Seed-824 pilots complete for visual diversity and least confidence; entropy and repeat seeds are in progress.** We compare ways to choose the next READ2016 TRAIN pages for Qwen3-VL-4B whole-page transcription. Every path starts from the same untouched base model and first 64 randomly selected pages. At each later round it selects 64 new pages, reveals only their true TRAIN transcripts to simulate annotation, then trains a fresh adapter from the same base model on all 128 or 192 selected pages. Training and evaluation settings are fixed.

K-center chooses pages that expand coverage in frozen Qwen visual-feature space. Least confidence chooses pages whose generated text has the lowest length-normalized probability under the current adapter. Random selection is the matched control. All saved checkpoints were evaluated on the same 42 official validation pages. **CER** is character edits per reference character and **WER** is word edits per reference word; lower is better. Outputs cut off by the fixed token cap count as empty predictions.

| Labelled TRAIN pages | Random CER / WER ↓ | K-center CER / WER ↓ | Least-confidence CER / WER ↓ | Truncated pages: random / k-center / confidence |
| ---: | ---: | ---: | ---: | ---: |
| 0 | 0.7902 / 1.0019 | same checkpoint | same checkpoint | 10 / 10 / 10 |
| 64 | 0.5025 / 0.8643 | same checkpoint | same checkpoint | 3 / 3 / 3 |
| 128 | 0.2946 / 0.6841 | 0.3113 / 0.6976 | 0.2825 / 0.6781 | 1 / 1 / 0 |
| 192 | 0.2112 / 0.5589 | 0.1994 / 0.5574 | 0.1930 / 0.5473 | 0 / 0 / 0 |

**The single-seed result is mixed.** K-center was worse than random at 128 pages, then lowered CER by 0.0118 at 192 pages while WER barely changed. Least confidence lowered CER by 0.0121 at 128 pages and 0.0182 at 192 pages; its WER was also lower at both budgets. The 128-page random run had one truncated validation page and least confidence had none; neither path truncated a page at 192. These differences do not yet show that either strategy generally beats random. The predeclared entropy pilot and paired runs with seeds 825 and 826 are still needed.

These are **official validation** results, not a document-independent final TEST result. Document grouping and possible model-pretraining overlap are unknown. Equal page counts also do not measure human annotation time.
