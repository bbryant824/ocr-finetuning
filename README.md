# Active Learning for OCR Annotation

A human-in-the-loop OCR annotation and training pipeline designed to reduce manual labeling effort in low-resource and domain-specific document collections.

The system will combine:

- An annotation interface for bounding boxes and text transcription
- OCR model inference and fine-tuning
- Uncertainty-based active learning to prioritize informative samples
- Iterative evaluation against random sampling

The project aims to measure whether active learning can achieve better OCR performance with less human annotation effort.
