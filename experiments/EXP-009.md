# EXP-009 — three-round page-text OCR engineering run

19 September 2026 UTC. This run narrows the **measured task to full-page transcription**; it does not detect or score line boxes. The earlier joint box/text failures remain in [EXP-008](EXP-008.md). [LightOnOCR-2-1B-base](https://huggingface.co/lightonai/LightOnOCR-2-1B-base) was chosen because its author recommends the base variant for fine-tuning. This is a model change, not a parser repair.

The original READ2016 v1.2.0 official split remained 350 TRAIN / 50 VAL, with unknown document grouping; no TEST pages were used. The source is the frozen EXP-008 snapshot (`781d319efaa94b68bdd8027a2ae4e01c`, manifest SHA-256 `ac0a02a218a2142c6ee92ae964e7828ddfc65545dd6ca12f695815bb4493bdd6`). Its existing local oracle supplied labels only for selected TRAIN pages. Seed 824 and the existing `select_pages` random strategy selected 64 new pages per round; each fit reset from the same original model and used the cumulative 64, 128 or 192 pages. The untouched original predicted before the first fit. The fixed recipe-selection slice was VAL `Seite0355`–`Seite0362`.

Model revision: `c1bc8eb6625be7b34178ff53481b242f7b8ffcb8`. Images were resized with longest side 1,540 pixels. Targets were the ordered original line transcriptions joined as NFC page text; **no validation labels entered training or inference**. Hugging Face Trainer + PEFT LoRA used all linear layers (rank 8, alpha 16, zero dropout), BF16, three epochs, batch 1 with accumulation 4, AdamW, learning rate `1e-4`, cosine decay and 10% warmup. Inference was greedy with repetition penalty 1.1 and a 1,536-new-token cap. `page-text-nfc-v1` scored failures as empty predictions. One selected page begins with a newline; its prompt and target merged into one token. The third fit used a one-token boundary mask correction, while preserving the original label. The first two selected sets contained no such mismatch. A failed partial third-fit path was retained; the successful retry reset from the original checkpoint.

This establishes a working **random-acquisition control** with improving page-text OCR on both the eight-page recipe slice and the untouched 42-page engineering slice. It does not establish an active-learning strategy advantage, useful line localization, document-independent generalization, pretraining disjointness or human-time saving. The next research comparison needs a model-informed selector at the same page budgets, multiple seeds and a documented document-grouped holdout; do not infer those outcomes from this run.
