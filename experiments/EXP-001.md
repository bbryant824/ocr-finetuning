the full source and generated the UUID above. With this run, the recorded settings
and exact client environment, the existing CLI command is:

```sh
PYTHONPATH=src python -m active_ocr.entrypoints.cli real preflight \
  "$RUNS" b567210090044847965952f4880e5fc2 "$RUNTIME_SETTINGS"
```

At the execution source, `ModalModel.check_run` in
`src/active_ocr/integrations/modal_model.py:806` constructs the required image set
from **all 400 frozen source pages**, then rejects the four-image bundle with
`ValueError: input bundle must contain exactly the frozen source images`.
The later image-size loop also assumes every source image is bundled.
This conflicts with the approved four-image upload scope. The failure is local
and occurs before transport creation or a paid model call.

Preserve this run and immutable input bundle. Execution is held pending a revised
release reconciling the full-source image requirement with upload scope. The
original source, fixed training/validation selection and held-out-label isolation
must remain intact; no production change was made for this failure.
