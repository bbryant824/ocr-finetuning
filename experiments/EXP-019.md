## Exact generation intervention

The positive conversation has eight correct crop/transcript support pairs. The negative conversation rotates the same support images left by one while retaining transcript order; preparation checks each resulting neighbouring transcript differs. Both retain the real query image and no target text. Positive/negative native positions and KV caches stay separate, but receive the same generated answer suffix.

For raw paired/mismatched logits zP/zM at the arm's actual generated prefix, use the existing repetition operator R and positive candidate set A:

```text
uP = R(zP)
A  = {v : uP[v] >= max(uP) + log(0.1)}
uC = R(zP + (zP - zM)), masked outside A
```

R applies native repetition penalty 1.1 once using the full positive prompt-plus-answer history. Set gP=argmax(uP), gC=argmax(uC); native argmax resolves ties. A gate stops iff its argmax is one of the native EOS IDs. Otherwise, choose the designated text rule's highest non-EOS score inside A. The paired argmax always lies in A. If either gate continues, a finite non-EOS candidate in A exists. There is no arbitrary logit-offset splice or probability-calibration assumption.

| Policy | Gate | Non-EOS ranking |
|---|---|---|
| `paired` | P | P |
| `contrastive` | C | C |
| `contrast_stopping` | C | P |
| `contrast_text` | P | C |

The first two are checked reconstruction endpoints and reuse their established complete predictions for science. Only the latter two generate 182 new transcriptions each. Both recompute decisions under their own generated prefixes; fixing the paired gate does not fix the old paired output length. Gate comparisons include text competition, so this does not isolate an EOS logit or visual/linguistic module. Reference transcripts enter only offline evaluation, never generation or output-length decisions.
