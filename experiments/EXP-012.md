# EXP-012 — READ2016 known-box region OCR

**Complete for the approved scope (25 September 2026): one random-selection baseline, seed 824, at 0/64/128/192 TRAIN pages.** K-center, entropy, least confidence, and seeds 825–826 were prepared but **not run** after the scope was narrowed. This is a separate Qwen pipeline for text recognition from supplied READ2016 line boxes. It does not detect boxes. The whole-page EXP-009–011 runners and results are unchanged. [Reader report](../results/EXP-012.md).

## Question and fixed method

Does crop-level transcription improve as more randomly selected TRAIN pages are labelled? The original Qwen model predicts before any fitting. Each of three rounds adds 64 new pages selected by deterministic random sampling with seed 824. READ2016's existing TRAIN transcripts simulate human annotation. Each round fits a new LoRA adapter **from the same pinned base model** on all selected pages, then scores the same 42 official VAL pages. The run stops after round three; validation scores do not choose the stopping point.

- Frozen source: READ2016 v1.2.0, source-run ID `781d319efaa94b68bdd8027a2ae4e01c`, manifest SHA-256 `ac0a02a218a2142c6ee92ae964e7828ddfc65545dd6ca12f695815bb4493bdd6`. Official split: 350 TRAIN pages / 8,367 lines and 50 VAL pages / 1,043 lines. Eight fixed VAL pages (`Seite0355`–`Seite0362`) checked the recipe; the other 42 pages / 861 ordered regions are the reported validation slice. Document grouping and possible base-model pretraining overlap are unknown. No final TEST was run.
- Input/output: PAGE-XML `TextLine` coordinates and source reading order are given. Crop the original JPEG at each axis-aligned box with eight clamped padding pixels; resize the longest crop edge to 1,024. The model returns line text only. Join predictions in source order to score page text. Empty or capped regions count as empty predictions; they are also counted separately. Geometry preflight passed for all 400 pages and 9,410 source boxes.
- Base model: `Qwen/Qwen3-VL-4B-Instruct` at revision `ebb281ec70b05090aa6165b016eac8ec08e71b17`, from the pinned Modal input bundle `94ed4f7f79d5d1110b7454c12a3b86d643cdb9dc0dece83d63734c2e4d87dcb6`. [Recipe](recipes/read2016-known-box-regions.json): one epoch, BF16, LoRA rank 8 / alpha 16, AdamW, learning rate 1e-4, batch size 1, gradient accumulation 4, cosine schedule, 10% warmup. Greedy inference with 64 new tokens and repetition penalty 1.1. Fit and inference both used Modal L4; output Volume `vo-J6KGzVVUq9jFE6mJFHO1PJ`.
- Evaluation: the local `page-text-nfc-v1` evaluator computes corpus character error rate (CER) and word error rate (WER) after ordered region transcription is joined. Only selected TRAIN transcripts enter remote fitting. Unlabelled records carry image/geometry but no ground-truth text; official VAL truth remains with `LocalOracle` for local scoring. This is validation, not a document-independent test.

The runner is [`region_pipeline.py`](../src/active_ocr/region_pipeline.py); its isolated recipe is above. The frozen selection and output identities are in the raw receipts below. This one-epoch known-box task is **not** a matched-input comparison with the whole-page EXP-011 result.

## Verified random-only result

The ignored local `audit.py` rechecked all four receipts against the frozen source: source and split/selection identities, 42 validation IDs, page order and CER/WER counts matched. The focused test separately checked that unlabelled records reject targets. Each round adds exactly 64 new TRAIN pages. Every checkpoint evaluated 42 pages / 861 regions against 17,718 reference characters and 2,675 reference words.

## Interrupted attempts and cost

Before the completed 128-page fit, [a first attempt](https://modal.com/apps/bowenbryant24/main/ap-Wn6RgAR4fPVSYtuqLIRWFo) lost local DNS at step 541/760 and left no completed adapter; its incomplete Volume directory is `region-exp012-random-seed824/round-2-attempt-29adc3b11bda42968cfff7b5daf64d21`. [A second attempt](https://modal.com/apps/bowenbryant24/main/ap-sYBL02zQIP30KERSbeZs20) finished 760 fit steps but the Modal workspace spend limit disabled validation; its adapter is **unvalidated**, retained separately on Volume at `/output/region-exp012-random-seed824/round-2-attempt-15f86f72af644f54b19467bb0ca27ebc/adapter/` and in ignored local `.local/verification/region-ocr-v2/recovery/seed824-round2-adapter/adapter/` (weight SHA-256 `d592d4e35c7a2d6b2f0f19435650cd0f96b14603ec1c39f4e5d26845b17299b9`). Neither is counted as a result. After the user raised the spend limit, a CPU-only readiness call succeeded; the 128-page stage was refit and fully validated. The 192-page app was preempted during an initial partial fit, then Modal automatically retried within the same app and completed fit, reload and validation. Only its final receipt is scored.

The saved Modal billing-report snapshot `.local/verification/region-ocr-v2/billing-final.json` (queried 2026-09-25 04:47 UTC, gross metered cost and subject to later billing updates) sums to **USD 6.073** for the six production app IDs in the table and failed attempts: L4 USD 4.222, memory USD 1.351, CPU USD 0.499. This includes failed fits and the preempted retry; it excludes the separate pilot and unrelated workspace jobs. It is a metered snapshot, not the final charged amount after credits.

The random baseline establishes that the isolated crop pipeline completes and accuracy improves with more selected labels. It cannot establish a page-selection advantage, document-disjoint generalization, human annotation savings or line detection. Further strategy experiments, if pursued, need equal-budget controls and independent seeds; they are outside this completed EXP-012 scope.
