# EXP-010 — Qwen full-page-text random-acquisition control

**Completed 20 September 2026.** This experiment reruns the READ2016 page-transcription task on Qwen3-VL-4B-Instruct, after archived EXP-008's unsuccessful joint box/text study. No box detection is trained or evaluated. [Reader interpretation](../results/EXP-010.md); [shared frozen configuration](recipes/read2016-page-text.json). EXP-009 remains the separately archived LightOnOCR control, with its historical runner and distinct checkpoints.

## Interpretation and limits

The measured question is whether **each model's OCR changes when more randomly chosen true page labels are supplied**. Random selection is the control: neither an uncertainty strategy nor annotation savings has been demonstrated. The Qwen/LightOn comparison uses the same READ pages, annotation budgets, numeric fit settings and metric, but **different architectures, tokenizers and chat inputs**; moreover EXP-009's published VAL42 table came from a separate LightOn pilot using different adapters/hardware than its runner's VAL8 table. Compare the models' learning curves with those caveats; do not present a paired 50-page test or infer that one selection strategy won. Official VAL document grouping and prior pretraining overlap remain unknown.
