# EXP-013 — Known-box page selection at smaller budgets

**Status: implementation corrected; GPU run resuming with preserved first-round results.** One seed (824), random, k-center, entropy and least confidence, at 0/24/48/72 labelled TRAIN pages. [Reader report](../results/EXP-013.md).

## Fixed method

Same frozen READ2016 source as [EXP-012](EXP-012.md): `781d319efaa94b68bdd8027a2ae4e01c`, manifest SHA-256 `ac0a02a218a2142c6ee92ae964e7828ddfc65545dd6ca12f695815bb4493bdd6`, 350 TRAIN and 50 official VAL pages. Keep the same 42-page / 861-line validation slice; the other eight VAL pages are not used for selector tuning. Document grouping and possible pretraining overlap remain unknown; there is no independent final test.

[Recipe](recipes/read2016-known-box-al-24.json) keeps EXP-012's pinned Qwen3-VL-4B revision `ebb281ec70b05090aa6165b016eac8ec08e71b17`, source boxes/reading order, eight-pixel padding, 1,024-edge crops, prompt, one epoch, rank-8/alpha-16 LoRA, learning rate 1e-4, batch 1 / accumulation 4, BF16 and 64-token greedy decoding. Each round resets from the original model on cumulative acquired pages. Fit, scoring and inference use L4, two CPU cores and 32 GiB RAM.

The acquisition unit is a page. Unlabelled scoring inspects the distinct line indices `floor(n/4)`, `floor(n/2)`, `floor(3n/4)`; all lines of a selected TRAIN page enter training. Each method selects its own first 24 pages. Entropy selects highest mean line token-normalized entropy; least confidence selects lowest mean line geometric token probability, both using raw logits along generated paths (including emitted EOS). Later pools use that method's preceding adapter. Ties use page IDs. Capped prefixes are scored without changing the rule and counted diagnostically. K-center uses normalized mean frozen Qwen visual features: first select the page nearest the pool centroid, then greedy farthest-first coverage, continuing from its own acquired set. Random uses seed `824 + round - 1`. There is no shared random warm start and no forced disjointness between methods.
