## Question and predeclared design

Does breaking demonstration associations provide useful recognition information beyond changing context order or corrupting the query? Keep the original Qwen3-VL-4B-Instruct revision ebb281ec70b05090aa6165b016eac8ec08e71b17 frozen. Use READ2016 supplied line boxes, the same seed824 TRAIN24/589 bank and exact per-query eight-support assignments. All 182 VAL8 lines (Seite0355–0362) are included; official validation has already been examined and is not a final test. No model fitting, retrieval, context resampling or coefficient search.

Let positive P contain (I_i,Y_i), and let pi be the left-by-one permutation. All arms use zP + (zP-zN), alpha 1/beta 0.1, at the same generated answer prefix in independent native caches. Apply the existing positive plausibility rule and repetition processor once. Native prompt, padding 8/longest edge1024, BF16 greedy, repetition 1.1, max 64 and EOS remain unchanged.

| Condition | Reference N | Execution |
|---|---|---|
| Paired ICL | None | Reuse verified EXP-015 pilot |
| Original mismatch contrast | (I_pi(i),Y_i), unchanged real query | Reuse verified EXP-018 pilot |
| Same wrong pairs, changed order | (I_i,Y_pi-inverse(i)), unchanged real query | 182 new outputs |
| Correct pairs, changed order | (I_pi(i),Y_pi(i)), unchanged real query | 182 new outputs |
| VCD-style query-noise contrast | Correct support pairs/order; only query pixels noised | 182 new outputs |

The inverse transcript permutation is essential: it preserves the original incorrect pair multiset. Correct-pair reordering preserves the original correct pair multiset. Both alter positions/recency; neither is a pure module intervention. Queries carry no target text; TRAIN labels appear only as declared support answers.

VCD adaptation: use the official [noise schedule](https://github.com/DAMO-NLP-SG/VCD/blob/master/vcd_utils/vcd_add_noise.py), fixed zero-based index500 of 1000. Noise is added after native resizing/normalization, before the vision encoder; no clipping or PIL roundtrip. Only the final image's patch rows change; image grids and token IDs remain identical. Still-image temporal duplicates receive identical Gaussian noise. A CPU float32 generator is independently seeded by the frozen query key. This adapts the published noise mechanism to Qwen3-VL crop ICL, not an exact replication of the original model/task benchmark.

## Interpretation rules frozen before outcomes

If both wrong-pair orders help while correct-pair order contrast does not reproduce the benefit, association-targeted negative construction remains plausible. If correct-pair order helps similarly, context reweighting/order is a competing account and a comparable-work positive-context alternative becomes relevant. If only the original ordering works, the reference is fragile. If query-noise contrast matches/wins, a special advantage of our support reference is unestablished. None proves superior glyph perception or pure linguistic/visual separation. Report mixed/negative outcomes without tuning a winner. Similar point estimates are not equivalence; one bank and one negative/noise realization do not establish robustness or publication novelty.
