## 1. Historical OCR: learning and context

This is the 8 October 2026 update. The earlier 27 September deck is retained after this new section. The research goal remains accurate historical transcription with limited labelled data. We first studied whether active selection improved adaptation, then whether inference-time examples could replace it. The recent controls now motivate a narrower question about which linguistic information helps recognition. No new linguistic experiment has run; the last slide is a proposal for review. Cloud costs are omitted from this presentation.

## 2. Adaptation works; the role of context is still open

The results support domain adaptation, not a general active-learning advantage. EXP-013 showed an early entropy lead which disappeared at larger budgets. EXP-015–016 showed that inference-time context helps much less than the saved 24-page LoRA. Removing support images barely changed Qwen performance, whereas mismatching them made it worse. EXP-017 tested the same protocol on LightOnOCR and exposed severe output failures. These are known-box line-recognition results on already-examined official validation, with one selected page bank; they cannot establish independent generalization, repeatability, human annotation savings or box detection.

## 3. Uncertainty leads early; random leads later

Purpose: reduce the overlap produced by the earlier 64-page budget and compare strategies from their own first selection, instead of using a shared random warm-start checkpoint. Qwen3-VL-4B-Instruct uses 0→24→48→72 TRAIN pages, seed 824, and one epoch per fresh-base cumulative LoRA fit. Random samples remaining pages. Entropy ranks the mean token-normalized entropy of three sampled line crops. Least confidence ranks the mean geometric token confidence of the same crops. K-center greedily covers normalized frozen visual features, initialized at the page nearest the centroid. Later uncertainty is scored with each arm’s own preceding adapter. Every selected page reveals all its TRAIN lines. The original-model evaluation is the checked EXP-012 receipt. This graph preserves the historical joined-page, cap-blanking metric; current ICL comparisons use raw line metrics instead. There were two capped original-model outputs and zero in the trained checkpoints. Entropy leads early, but random has the lowest CER/WER at 48 and 72 pages. This is a one-seed pilot, not proven annotation savings.

## 4. The advantage depends on the label budget

These are the permanent EXP-013 results, not recomputed with the later line-level evaluator. At 24 pages CER is random .410374, k-center .446947, entropy .355909, least confidence .374026; WER .825421, .852336, .795140, .796262. At 48 pages random .235749/.644486 has the best rates; at 72 pages random .175020/.552897 remains best. Entropy/least-confidence selections overlap strongly, reaching 37 of 72 pages. Page budgets do not equalize line counts: the 24-page arms contain 589/501/580/584 lines and 72-page arms contain 1725/1658/1713/1659. Adapter construction was not fully seeded. Therefore small strategy gaps combine selection with training variation; this does not prove active selection is ineffective in general. It motivates understanding the adaptation signal before designing another selection strategy.

## 5. ICL supplies examples before one query crop

“After finding that fine-tuning improves historical OCR, I wanted to investigate whether examples supplied during inference could provide similar benefits.
I constructed a bank from the same 24 randomly selected training pages, containing 589 labelled lines. For each query, I provide eight or twenty-four example crops with their transcripts, followed by one validation crop whose transcript is hidden.
Qwen then generates only that query’s transcription. Its parameters remain unchanged, and each query uses a fresh conversation.
Before the full experiment, I checked this process on a small diagnostic set, including whether the images, transcripts and context length were handled correctly.”




EXP-014 is a development and test record, not a full effectiveness experiment. It built native multi-turn ICL using the exact EXP-013 random 24-page bank (589 labelled TRAIN lines). For each VAL query a seeded draw selects 24 distinct support IDs; the 8-shot set is its prefix. Different queries can receive different supports. Each paired demonstration is one user crop followed by its true TRAIN transcript as an assistant turn. The final user turn contains the real VAL crop and the instruction to return only its transcript. The model runs frozen, in inference mode, with no optimizer, adapter or prior-query history. Crops use the supplied READ2016 line polygon envelope, 8-pixel padding, RGB, and longest edge 1024. Greedy BF16 decoding uses repetition penalty 1.1 and at most 64 new tokens. Eight diagnostic lines tested 0/8/24 shots before scaling. The largest final 24-shot diagnostic used 25 images and 3935 input tokens plus 64 output tokens. The full EXP-015 maximum later reached 4422 tokens, still below the pinned Qwen context limit. HF Transformers performs inference; HF/PEFT produced the reference LoRA; Modal L4 executes the existing pipeline. Known locations are supplied, not predicted.

Prompt and context details, verified 8 October 2026:
The exact instruction P is: “Transcribe only the text in this cropped line. Return only the transcription.” It appears in every demonstration user turn and again in the final query user turn. There is no explicit or template-added system message in this pinned Qwen configuration. Each user turn contains an actual RGB crop followed by P. Each demonstration assistant turn contains its true TRAIN transcript. Repeat for k examples; then supply the real VAL crop followed by P. End with an empty assistant generation prefix. The supplied demonstration transcripts are context, not model-generated answers.

Full message structure:
USER: TRAIN crop 1 + P
ASSISTANT: true TRAIN transcript 1
… repeat for k examples …
USER: VAL query crop + P
ASSISTANT: generation begins here.

The Hugging Face processor applies the model’s native chat template, tokenizes text and special role tokens, expands image placeholders into resolution-dependent visual tokens, and supplies crop pixel tensors. In Qwen serialization, user turns are enclosed by <|im_start|>user and <|im_end|>; an image is represented by <|vision_start|><|image_pad|><|vision_end|> before expansion. Generation starts after <|im_start|>assistant. No coordinates, query transcript, or previous query history enter the prompt. Greedy model.generate runs once for each query; only newly generated tokens are decoded. Original EXP-015 settings were max_new_tokens=64, do_sample=False and repetition_penalty=1.1; the later 1.0 check is reported separately.

The configured limit is min(model text max_position_embeddings, tokenizer model_max_length): 262,144 tokens for pinned Qwen3-VL-4B ebb281ec70b05090aa6165b016eac8ec08e71b17. The full 8-shot run used 9 images and at most 1,826 input tokens (1,890 including the 64-token output reserve); 24-shot used 25 images and at most 4,358 input tokens (4,422 with reserve). The limit includes transcript text, repeated instructions, chat markers and expanded image tokens, not a number of pages. Each query is checked for capacity and complete image-token expansion. A configured limit is not proof that a GPU can hold arbitrary inputs at that limit. EXP-014’s diagnostic maximum 3,999 is a different small-test figure. LightOnOCR’s pinned configuration has 16,384 positions and EXP-017’s maximum total allowance was 5,335; it uses its own processor/template, not Qwen’s ChatML.

Different queries draw reproducible supports from the same 589-line TRAIN bank; the eight examples are a prefix of that query’s 24 examples. Text-only controls remove only demonstration images; the query image and assistant transcripts remain. Mismatched controls rotate demonstration crops while retaining transcripts. Prediction is repeated over all 861 VAL42 lines; VAL answers are loaded for evaluation only. Source: src/active_ocr/region_pipeline.py::_inputs; src/active_ocr/icl.py::check_input_capacity/run_queries; experiments/EXP-015.md.

## 7. ICL improves Qwen, but remains far behind LoRA

Purpose: test whether prompting the original model with labelled examples can approach adaptation without updating weights. EXP-015 generated 1722 full-validation predictions: 8-shot and 24-shot paired ICL on the same 861 VAL42 lines. The original-model reference comes from verified EXP-012; the 24-page random LoRA comes from EXP-013. No reference was silently rerun. Values on this slide are the raw line-level NFC CER/WER recomputed in EXP-016, retaining capped strings: zero .863601/1.174579; paired8 .798331/1.121121; paired24 .808924/1.122243; LoRA24 .430499/.834766. CER is total character edits divided by 16899 reference characters; WER is total word edits divided by 2675 words. Eight-shot ICL reduces CER by 6.53 percentage points, versus 43.31 points for the saved LoRA. Twenty-four supports are not consistently better than eight. Although the bank matches, training consumes all 589 crop/text pairs while each ICL query sees a subset. The previous LoRA includes both visual and language-component modules. The result is not a clean causal division between language learning and visual learning.

## 8. Do support images add useful information?

EXP-016 asks whether the modest ICL gain needs correctly paired visual demonstrations. Paired results are reused from EXP-015. Transcript-only removes demonstration images, preserving transcripts and native chat turn order. Mismatched pairs rotate demonstration images left by one, preserving the same image and transcript multisets and ensuring no accidental matched transcript. The actual query image is present in all conditions, so transcript-only does not mean text-only OCR. The full four new conditions generate 3444 predictions after focused local and VAL8 checks. Chen et al. studied demonstration-image removal in VQA/captioning and found a strong text role while the query image remained important. Their masked cross-attention explanation is architecture-specific, not established for Qwen. Bertini Baldassini et al. show task-dependent effects of alignment, order and copying; they motivate these controls rather than predict the mechanism in historical OCR. Papers: https://arxiv.org/html/2311.18021v2 ; https://arxiv.org/html/2404.15736v2

## 9. Text-only ICL is close; mismatched pairs hurt

The main comparison uses raw line-level metrics. Paired8/24 CER .798331/.808924 and WER 1.121121/1.122243; text-only8/24 CER .805965/.798095 and WER 1.130093/1.098692; mismatch8/24 CER .968874/.948695 and WER 1.293084/1.263551. The corpus has 16899 characters and 2675 words. Paired8 and text-only24 differ by four character edits: 13491 versus 13487. This is descriptive closeness, not tested statistical equivalence. Caps for the six conditions are 2/3, 1/0 and 2/5. The zero-page model produces Cyrillic in 164 lines despite no Cyrillic in the references; paired8/24 has 2/0, text-only8/24 4/1, mismatch8/24 1/0. Therefore the expected script can be restored while CER gets worse. Correct associations matter under this protocol, but we cannot attribute the effects to visual learning, grammar learning or a particular attention path without additional controls.

## 11. Retaining failed outputs changes the interpretation

Saved-output and local processor audits checked TRAIN/VAL isolation, bank labels and reproducible support IDs; the native chat image/text order and shortest/longest prompts; generated-token-only decoding; fresh-query state; coverage, cache/receipt identities and hashes. Independent edit-distance recomputation reproduced metrics. That establishes the tested data flow, not model quality. The EXP-015 follow-up compared penalty 1.1 with 1.0 on all 182 VAL8 lines at 0/8/24 shots. Across those conditions the mean historical page CER fell .766122→.737172, but mean raw line CER worsened .834989→.985223, and caps rose 2→25. Even the same page aggregation while retaining capped text worsened .790843→.912499, confirming that blanking drove the misleading apparent gain. Penalty 1.1 was retained; no full VAL42 penalty-1.0 run was silently substituted. EXP-017 similarly reverses under raw scoring: LightOn zero/paired24 historical CER .899142/.838187 versus raw 1.523463/3.597373. Current comparisons retain raw output, including caps, and score per-line NFC text. Historical EXP-013 values remain explicitly labelled.

## 12. The READ result is difficult in the cited ICL study too

“I compared these observations with Ayllon and colleagues’ handwritten-text-recognition study.
On READ, their Qwen eight-billion model also showed limited average ICL improvement: CER was 80.95% without examples, 81.96% with eight examples, and 78.78% with sixteen.
Their best sixteen-example context achieved 55.61%, but it was identified using the correct answer. That demonstrates context sensitivity rather than a deployable selection method.
Our setup differs in model size, evaluation data and context sampling. Nevertheless, the paper shows that strong average ICL gains should not be assumed for this difficult collection.”


Ayllon, Gandia and Calvo-Zaragoza, Exploring In-Context Learning for Handwritten Text Recognition, 2026 arXiv v1 preprint, reports Qwen3-VL-8B READ/ICFHR16 in-domain mean CER 80.95% at zero shots, 81.96% at eight and 78.78% at sixteen. It samples 30 contexts per query. Its oracle-best sixteen-shot 55.61% uses ground truth to select the best context and is not a usable inference policy. Our Qwen4B, VAL42 slice, single draw, dataset export and decoding/evaluator differ, so the numbers are descriptive comparisons rather than head-to-head model performance. Both show that READ remains difficult. Chen et al. WACV2025 studies different multimodal architectures and VQA/captioning; text-dominant demonstrations do not imply that the query image is unnecessary. Bertini Baldassini et al. CVPRW2024 find task-dependent multimodal pairing/order effects. Neither directly proves the mechanism of our historical-OCR observations. Sources: https://arxiv.org/html/2609.37195v1 ; https://arxiv.org/html/2311.18021v2 ; https://arxiv.org/html/2404.15736v2

Prompt-format comparison:
Ayllon et al. v1 (§3.3/§4.4) arrange instruction → labelled line-image demonstrations → query image → transcription. In-domain supports come from the same collection’s TRAIN split; cross-domain supports come from another. They use 0/1/2/4/8/16 shots, 30 contexts/query and vLLM; we use 0/8/24, one context/query and HF. Stopping at 16 reflects marginal benefit, not declared capacity exhaustion. Their methods do not publish the verbatim prompt, numerical context limits, actual token lengths or complete decoding parameters. This is methodological alignment, not exact replication.
Chen et al. similarly formalize demonstrations as image/instruction/response triples followed by a query image/instruction, on different models and tasks.

## 13. Text context helps unevenly across lines

The latest research analysis recomputed character edits for the same 861 queries across eight conditions and verified source, bank, recipes, coverage and reused receipts. Transcript-only24 improves 384 lines, worsens 316 and ties 161; LoRA24 improves 774, worsens 30 and ties 57. The baseline has Cyrillic in 164 lines even though references have none. Text-only24 saves 1107 total edits versus baseline: 509 (46.0%) in those 164 lines and 598 among the other 697. That subgroup still has 2421 edits over 2802 reference characters, or 86.4% CER. Removing wrong-script behavior is therefore insufficient for accurate transcription. Subgroup membership uses a baseline prediction and may correlate with difficulty: this locates changes but does not causally attribute 46% to script correction or offer an inference-time routing rule. Raw ICL gains remain small while many individual lines deteriorate. The saved all-linear LoRA contains 208 visual and 504 language-component tensors, so its large gain cannot be attributed solely to language learning. Evidence: research/linguistic-context-historical-ocr.md and the existing EXP-016 saved-output bundle.

## 14. Language priors help, but can also rewrite the source

The previous turn reviewed 19 primary studies with the Research agent. Meyer et al. 2026 preprint trains a word recognizer to accept projected character-five-gram priors and changes its target text bank at inference. IAM k-means target CER is 18.0%→10.1%; ordinary rescoring is 9.7% and the combination 8.4%, so injection is not uniquely superior. This is not a drop-in Qwen technique and is not training-free overall. Kanerva et al. RESOURCEFUL2025 reports Finnish relative CER improvement +11.9% against normalized truth versus −10.1% against literal truth; evaluation policy can reverse the conclusion. Vesalainen et al. 2026 preprint compares fine-tuned models on historical printed English and reports lexical modernization such as Antient→Ancient; this is not a READ handwriting benchmark. HisDocOCR, Findings ACL2026, freezes vision while adapting language components with image-conditioned objectives, showing why a language-component adapter is not synonymous with language-only learning. These papers motivate controlled language studies rather than a claim that grammar causes the existing gains. Sources: https://arxiv.org/html/2603.03930v1 ; https://aclanthology.org/2025.resourceful-1.8/ ; https://arxiv.org/html/2602.14524v1 ; https://aclanthology.org/2026.findings-acl.301.pdf

## 15. Next: isolate the useful linguistic information

These are staged proposals, not approved experiments. Start with the existing original Qwen and fixed seed-824 24-page bank, eight transcript supports, and the 182-line VAL8 slice. Arm A reuses the current zero-shot prompt only after exact identity checks. B adds collection-level language metadata verified independently of validation labels; do not force every mixed German/Latin line into German. C adds intact TRAIN transcripts using fixed support draws. D uses the same transcripts with shuffled word order. The real query image, processing, decoding and raw-line evaluator remain fixed. B−A tests explicit priming; C−B tests transcript information; C−D probes ordered text but is not a pure grammar intervention, since tokenization and local statistics may change. A small correctness gate precedes the pilot, and only informative effects justify a conditional VAL42 confirmation. If language adaptation remains central, design a newly seeded text-only versus image/transcript adaptation comparison with matched language-component modules, frozen visual weights and target-token exposure. The saved all-linear LoRA remains a reference, not that matched control. The tiny 1940-word bank may overfit or be mismatched to a text-only objective; its feasibility must be checked before scaling. Predicted neighbouring context is a later alternative, using frozen predictions rather than VAL truth; it is not included automatically. Potential contribution is a controlled explanation of useful language conditioning and its error profile, not claiming ICL, language priors or OCR correction are new inventions.
