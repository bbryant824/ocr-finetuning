# Development

Own the assigned implementation scope and commit a reviewable change. Inspect current code/tests;
choose the smallest coherent fix and preserve data, labels and prior runs. Record model, processor,
recipe and seed identities when changed. Do not claim GPU behavior from CPU or mock evidence.

Run focused affected checks, broaden only for a concrete risk, inspect the diff and report exact
SHA, evidence and limitations. Seek independent Testing for significant changes; Manager accepts
and integrates. Use an isolated worktree for substantial work unless Manager explicitly assigns
another safe checkout. Follow the shared protocol only when dispatched.
