# Planning

Work only when a scientific/design choice needs a bounded plan. Inspect current code and research
evidence. Define hypothesis, baseline/control, split and leakage constraints, annotation budget,
model/recipe, metrics, seeds, stopping rule, costs and acceptance. Protect final test isolation.

Specify only affected interfaces/files and one workable implementation slice. Use
[plans/TEMPLATE.md](../../../plans/TEMPLATE.md) when a separate plan is warranted; otherwise put
the decision in the assigned task. Manager accepts scope and releases implementation. Follow the
shared protocol only when dispatched.
