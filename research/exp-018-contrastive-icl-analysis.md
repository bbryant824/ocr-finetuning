# EXP-018: interpreting contrastive in-context handwriting recognition

Review date: 17 October 2026. **Completed analysis of independently audited EXP-018 and its approved 16-case query-image follow-up. The follow-up failed its advance screen; no 64-case confirmation was run.** Primary-paper methods and relevant appendices were checked on 16–17 October.

## Question and current conclusion

Does contrasting correctly paired and mismatched demonstrations improve recognition beyond ordinary paired or transcript-only context, with the model, labelled bank and query images fixed?

**Measured result:** on 861 validation lines, contrastive-eight reaches **75.5429% CER**, improving on paired-eight by **4.2902 percentage points** and transcript-only-eight by **5.0536 points**. The gain observed in the pilot carries over to disjoint pages under the unchanged recipe. Insertion/deletion changes account for most of the net gain; substitution errors increase slightly against transcript-only support. The result supports useful inference-time reweighting of this model's sequence preferences, not a demonstrated improvement in glyph recognition or a separation of linguistic and visual knowledge. Harmful changes remain frequent, absolute error remains high, and the saved LoRA24 reference is substantially stronger.

VAL8 is Seite0355–0362; VAL42 is Seite0363–0404. They have zero page overlap: the latter is 861 additional queries, not an extension containing the 182 pilot queries. Both belong to official validation; VAL42 has already been examined in earlier experiments. Neither is an untouched final test or evidence of independence between documents/writers. This is confirmation across these pages, not repeated-bank/context robustness, fine-tuning parity or reduced annotation effort.

**Current recommendation after EXP-021, 18 October 2026:** the approved VAL42 comparison is complete and audited in [EXP-021](../results/EXP-021.md). Ordinary CER 86.36/81.04/79.83% becomes 80.95/76.44/75.50% under query contrast at 0/2/8 shots. Two supports save another 763 edits (4.52 points); eight add 159 (0.94 points). The insertion-reduction / support-content pattern carries over descriptively, and the common 855-line sensitivity retains both benefits. However, zero-shot contrast no longer beats ordinary eight-shot and introduces one runaway; exact-line counts decline. Full query-noise and EXP-018 mismatch references differ by only eight edits, so general reference superiority is unestablished. These are performance/error patterns, not a causal vision/language decomposition, fine-tuning parity or a new method. Next proposal revised after user review: repeating EXP-016 modality controls at a smaller shot count adds limited information. Instead test the first ordinary/contrast token divergence with both fixed subsequent decoders, measuring complete-output CER/WER. Reuse EXP-021 two-shot baselines and exact query noise on the first eight VAL42 pages (105 queries; 92 divergent sequences, at most 184 new continuations). This tests early path steering versus continued correction, not pure visual/language attribution; it is a proposed development study, not an established novel method. No follow-up, tuning or final-test access is approved or running. The 26-source comparison below remains the dated review; earlier pending-study statements are historical. The paper-level goal remains usable support information → recognition-linked explanation → justified improvement and independent transfer.

## Fixed comparison and evidence scope

This is German historical handwriting from READ2016v1.2.0, with source line boxes supplied. It measures line recognition, not text detection or end-to-end page OCR. Original `Qwen/Qwen3-VL-4B-Instruct` weights at revision `ebb281ec70b05090aa6165b016eac8ec08e71b17` remain frozen. The labelled bank is the EXP-013 seed-824 selection: 24 TRAIN pages, 589 lines. Each query receives the same deterministic eight-support draw used by the corresponding controls. No validation transcription enters generation or support selection.

Let `z+` and `z−` denote next-token raw logits under paired and mismatched support respectively, at the **same generated answer prefix**. The implemented score is `zC = z+ + (z+ − z−)`, with α=1 and β=0.1 positive-branch plausibility restriction. Repetition processing is applied once to the combined scores; native branch positions and caches remain separate. The mismatch cyclically rotates the same eight images while keeping transcripts/order fixed. Both branches retain the real query image. This perturbs demonstration associations; it does not remove query vision or supply a pure language-model distribution.

RGB crops, padding 8, longest edge 1024, native instruction, BF16, greedy decoding, repetition penalty 1.1 and maximum 64 new tokens remain fixed. Primary scoring is `line-text-nfc-raw-v1`: retain every generated string, sum per-line edit counts, then divide by reference characters/words. WER can exceed 100% because insertions count. Historical page scoring that empties capped outputs is unsuitable as the headline comparison.

The [development record, §7](icl-decoding-and-adaptation-scope.md#7-completed-bounded-development--12-october-2026) documents execution at `2942cdd`, recipe identity `f88f3f6d120162b962c5293fef7ccfe9b2728af07b64d7d1c053704282f543a1`, Torch 2.8.0+cu128 and Transformers 5.6.0. Its saved audit confirms all 182 outputs, three native-equivalence contrastive replays, six query pairs and final lens calibration. This review inspected those receipts; it did not rerun inference or claim a fresh GPU verification.

## What the diagnostic establishes

All six preselected query swaps changed the transcript. Four outputs moved closer to the replacement image's reference; two tied. All anchor transcripts remained imperfect. This demonstrates an effect of the changed query pixels in these cases. It does not establish correct reading, population-level grounding or the mechanism of the contrastive gain.

The 24 lens contexts use exact saved **transcript-only-eight output token IDs**, for up to three answer positions. They do not use reference transcripts or reconstructed paired-output tokens. At the first answer position the pre-block readouts are identical; differences appear after the first decoder block. Final log-probability differences for the original run's selected first token range from 0.8465 to 7.9537 nats under original versus replacement images. These are selection-conditioned query-swap effects, not image-removal gain or a percentage attributable to vision.

A maximum final-readout calibration error of 0.0 validates that final projection against native logits. It does not establish semantic faithfulness of intermediate projections. Late separation cannot establish that vision recognized the correct text before language overrode it. The paired and mismatched branches have separate hidden trajectories; their score combination does not create a single contrastive hidden trajectory.

## Interpretation and claim boundaries

**Supported by both slices:** the fixed support-context contrast improves aggregate recognition beyond paired and transcript-only support on these pages. The pilot independently shows query-pixel effects in six controlled examples. These facts do not establish that the improvements occur because of those query effects. Existing checks support correct execution of the specified decoder within their tested scope.

**Competing hypotheses, not established mechanisms:** the contrast may amplify query-specific evidence about what to continue or omit, suppress preferences induced by conflicting supports, or regularize output length/repetition without improving visual interpretation. These can coexist. The insertion/deletion findings make sequence behaviour a stronger immediate target than a glyph-substitution account. They do not identify a purely linguistic mechanism: visual errors can also insert or omit text. Subtracting a poorly performing distribution does not isolate newly learned mappings, and useful language priors may help ambiguous ink. One bank, one support draw per query and one negative permutation cannot establish robustness to context choice.

**Potential contribution:** a controlled empirical test of mismatched-support contrast for this fixed-bank historical-handwriting setup, with explicit transcript-only and adapted-model references and preserved harmful outcomes. Generic contrastive OCR, ICCD, frozen-VLM handwriting ICL and lens visualizations are prior art. The focused search does not establish that the exact combination is first. No annotation-saving or active-learning strategy conclusion follows from reusing one random labelled bank.

**Efficiency remains unmeasured comparatively.** The full run records 1,623.02 seconds of query work and 9.06 GiB maximum allocated GPU memory on L4 with Torch 2.8.0+cu128 / Transformers 5.6.0. The saved app-state receipt records stopped/zero tasks at 00:04:18 SGT on 17 October, after creation at 23:10:54 on 16 October. App lifetime and summed query-work time are different quantities. The query timer includes input preparation after model/image loading, whereas historical native timers exclude preparation. These do not establish relative speed, billing cost, cost-effectiveness or memory advantage. Two decoding branches add work, but no exact runtime multiplier is inferred. No new model or adapter was produced.

## Single next question: query evidence in improvements versus harms

**Predeclared recommendation: C, a small teacher-forced query-image intervention study. Approved and executed 17 October 2026; see the completed diagnostic below.** Ask: **Are the continuation preferences associated with contrastive improvements over transcript-only output more query-specific than those associated with harm, or are they compatible with largely query-insensitive sequence regularization?** The full gain justifies retaining the small diagnostic, while its insertion/deletion composition changes the hypothesis and gate: assess continuation and stopping choices, not a claim of better glyph reading. This connects controlled query effects to scored outcomes; sensitivity alone is not success. Its contribution would be a bounded empirical association, not a new lens or a separation into pure linguistic and visual components.

| Alternative | What it tests and why it is not the default next step |
|---|---|
| **A: one alternative fixed derangement** | Tests dependence on the chosen wrong associations while preserving image/text multisets and image count. This is the cleanest narrow robustness check. Changed image order can still alter positional interactions, and two permutations cannot establish general robustness. It does not explain why transcript-only supports rival paired ones or whether an improvement uses correct query evidence. Prefer it if the immediate objective becomes replication of the decoder gain rather than explanation. |
| **B: transcript-only-support negative, real query retained** | Tests whether amplifying paired-versus-transcript-only score differences improves decoding without introducing wrong support images. Keep α, β, positive branch and queries fixed. However, removing eight images changes image count, prompt length, positions and contextual interactions; it is not subtraction of a pure language model. A win would support a useful alternative contrast, not prove visual grounding. Prefer it if the objective changes to improving recognition and the existing mismatch branch is the practical concern. |
| **C: observed-prefix query intervention** | Holds each support context and generated prefix fixed while replacing only query pixels with a matched-grid real crop. Compare paired, mismatched and transcript-only contexts at the same answer decision. This tests whether their preferences depend on the particular query and whether that dependence differs between net improvements and harms. It cannot prove that a specific glyph was recognized correctly or eliminate interactions between support images and positional layout. Its advantage is answering the attribution question directly enough to reject simple explanations without launching another decoding method. |

These choices follow the distinctions in the primary-source table: ICCD motivates association contrasts; VCD changes query evidence; Reading or Guessing separates image dependence from correctness; LatentLens limits semantic claims from intermediate readouts. Neither A nor B alone identifies the cause of a gain. C is also a conditional diagnostic, not a complete mechanistic explanation.

### Predeclared study (approved and executed pilot; conditional confirmation stopped)

Use existing exact contrastive and transcript-only token sequences. At their **first differing token**, take the shared generated prefix and two observed candidates, **including EOS when one candidate stops**. This revises the earlier non-EOS-only proposal to reflect the observed sequence-length findings without adding evaluations. Do not retokenize stripped text or teacher-force reference text. Classify lines as improved or harmed by whole-line raw character edits; a net line improvement does **not** label its first differing token as correct. Attach each line's output-length difference and alignment-based substitution/deletion/insertion changes for interpretation. Reference text is used only offline. The first divergence is an early decision probe: it need not coincide with the edits responsible for the final gain, and a null effect there cannot rule out later query-dependent stopping or repetition control.

For each eligible line, score both candidates under paired (`P`), mismatched (`M`) and transcript-only (`T`) supports with (i) the original query and (ii) one deterministically chosen real donor crop from another page with identical processor-grid geometry. Freeze support IDs/order, prompt tokens and generated prefix. Verify that changing the query preserves token IDs, image count and native position/cache geometry **within each context**. The three support contexts need not have identical positions to one another; compare within-context query effects and disclose that their differences can include context-layout interactions. A donor image is a controlled replacement, not absence of vision.

Let `m_s(I)` be the raw-logit margin of the contrastive candidate over the transcript-only candidate under context `s`, image `I` and their shared prefix. Define `D_s = m_s(original) − m_s(donor)`, `D_C = 2D_P − D_M`, and `G = D_C − D_T`. `G` describes excess query sensitivity of the raw contrastive margin; it is not an attributable amount of visual knowledge. Contrastive reweighting also changes score scale. Therefore record vocabulary ranks of both candidates under `zP`, `zM`, `zT` and `2zP−zM`; use the analogous query-induced change in rank advantage as a scale-insensitive cross-check, computed from the same evaluations. Larger logit differences alone cannot pass the interpretation gate.

Concretely, rank advantage is `rank(transcript-only candidate) − rank(contrastive candidate)`, where rank is one plus the number of strictly higher vocabulary scores. **Revised research question:** can a contrastive decoder make query-image evidence more useful for historical recognition while retaining the beneficial score changes induced by historical-text demonstrations?

Contrastive subtraction is selective reweighting, not acquisition of new visual knowledge. An inaccurate reference need not be a useful critic: correct tokens may be likely under both branches, while an incorrect token can be rewarded because it is even less likely under the reference. Language priors can resolve ambiguous ink, and stronger image dependence can amplify visually triggered errors. Neither branch is a pure vision or language channel.

For a focused first comparison, retain the existing **eight transcript-only demonstrations**, original query image, Qwen revision, bank/seed and decoding settings. This makes use of the observed transcript-context benefit and keeps one query image per branch. Both new rules must share this positive context; the existing paired/mismatch decoder is an additional reference with a different positive prompt, not a pure reference-branch ablation.

At a common generated prefix, let `s8(I)` be raw scores with eight transcript supports and original query `I`; `s0(I)` uses no demonstrations. Let `I~` be one fixed degradation of the same crop, preserving geometry and intended transcription. A fixed blur is a candidate, not a validated language-only intervention; choose and freeze its specification before performance comparison and report if it unexpectedly improves native OCR.

- Ordinary visual contrast with ICL: `s_naive = s8(I) + α[s8(I) − s8(I~)]`.
- Candidate preserving the ICL score increment: `s_preserve = s8(I) + α[s0(I) − s0(I~)]`.

The latter requires three native distributions/caches. Define `Δ8(I)=s8(I)−s0(I)`. Before repetition processing/filtering, its score is exactly zero-shot visual contrast plus the original-query increment `Δ8(I)`. The difference `s_naive−s_preserve = α[Δ8(I)−Δ8(I~)]` identifies the context/visual-condition interaction that the ordinary contrast additionally reweights. This algebra does not identify a pure linguistic component or guarantee that preserving the increment preserves accuracy. It adapts the instruction-preservation principle to demonstration conditioning; novelty and utility are not established.

**Falsifiable hypotheses:** useful historical context is partly removed/distorted by the ordinary reference contrast, so preserving its original increment improves recognition; alternatively, context-conditioned visual differences are useful, so removing that interaction harms recognition. A third possibility is that zero-shot visual differences amplify this model's existing glyph/script confusions, causing both methods to fail. Negative outcomes remain informative only with adequate controls and replication.

**Proposed stages:** first verify α0 native equivalence, independent native positions/shared suffixes, unchanged query geometry, no label leakage and stopping on a few crops. Then generate complete outputs on the existing VAL8/182 development lines for the two fixed rules, with a native degraded-query control; reuse exactly matched zero, text-only, paired and mismatch-contrast references. Use the same original-image eight-shot plausibility filter and repetition processing for both new rules. Keep α=1, β=0.1, penalty=1.1 and max64 initially; no grid search, retrieval or fitting. Compare every method to its own positive baseline and to the current best decoder, and analyse raw CER/WER, gains/harms, S/D/I, script/length failures, EOS and candidate admission. Inspect selected shared-prefix score differences only after complete-output outcomes; avoid another outcome-selected probe as the primary efficacy gate.

A candidate merits further work only if it improves recognition under the fixed comparison and the benefit is not solely token-limit handling, a few outliers or one page. If promising, freeze the method, repeat support draws from the same seed-824 bank, include zero-shot visual contrast before attributing any gain to ICL, and verify on an untouched evaluation and an independent historical setting before broader claims. VAL42 remains previously examined validation, not an untouched final test. If both candidates fail, pause this extension rather than tune references until a favourable result appears. ### Current clarification: generic properties before decoder design

**User clarification supersedes the view/retrieval/correction recommendations above.** The research target is a general property of frozen-VLM inference that can be measured and used to improve ICL OCR decoding. The earlier unapproved preservation, extra-view, retrieval, correction and reranking options are not selected. The published inspirations and offline candidate-selection findings remain evidence/references, not execution releases. The 69.73% oracle bound applies only to choosing existing whole-line outputs; it does not limit a new generative decoder.

Three property hypotheses are worth distinguishing:

1. **Query-dependent use of example associations versus general prompt preference.** Correct versus mismatched supports can change a token's preference even without usable query evidence. Our existing contrast combines this reference-dependent background preference with the part that changes when query evidence is present. The hypothesis is that separately controlling these contributions improves recognition. Both can be beneficial; query-independent stopping/style changes are not automatically errors.
2. **Reliability under valid context variations.** Token evidence that is stable across orderings or draws of correctly paired supports may be more reliable than a preference driven by one context. A decoder could aggregate image-conditioned evidence and penalize unstable corrections. Stability of raw probability alone is insufficient: a common wrong word can be consistently likely. This is distinct from the earlier saved-string medoid and is not validated by that calculation.
3. **Information lost between intermediate and final predictions.** If query-supported alternatives are present at intermediate layers and then suppressed, layer-informed correction may recover useful evidence. Earlier does not mean more visual or more correct. Raw logit-lens scores across depths need calibration/controls, and attention magnitude alone does not establish correctness.

The following four-condition illustration was considered but is not the selected direction: dependence on query pixels does not establish recognition utility. The bounded correctness study below supersedes its proposed execution. At an identical generated prefix, let `p+(y|I)` and `p−(y|I)` denote next-token distributions with correct and mismatched support associations respectively, retaining the same transcripts/order. Let `I0` denote a declared query-evidence-removed reference; the support bank remains intact. Define:

`D_real(y) = log p+(y|I) − log p−(y|I)`

`D_ref(y) = log p+(y|I0) − log p−(y|I0)`

`interaction(y) = D_real(y) − D_ref(y)`

An illustrative objective is `S(y) = log p+(y|I) + a[D_real(y) − b D_ref(y)]`. Setting `b=0` gives ordinary mapping contrast at the unprocessed scoring-objective level; `b=1` subtracts the reference-condition mapping preference. This is a proposal, not a proven rule. A correction that behaves identically with and without query evidence has zero interaction increment. The ordinary full-ICL prediction remains the base, retaining its useful linguistic conditioning. An image-sensitive error can still receive a large increment. Reference choice, near-zero probabilities, candidate admission, repetition processing and stopping require explicit controls; log-probability and raw-logit combinations are not assumed interchangeable through nonlinear processors. Native zero-strength equivalence must be verified before any experiment.

This is an operational difference of conditional preferences, **not** exact Shannon synergy, a percentage of visual contribution, or proof of causal visual learning. A blank/removed query can change task behaviour; the estimate depends on that intervention and must survive a reasonable alternative before mechanistic claims. Four native conditions also add inference cost. If the reference contribution is negligible, uninformative about harmful corrections, or useful for length control, the added complexity may not help.

Relevant primary sources checked on 17 October: [contextual calibration, Zhao et al., ICML 2021](https://arxiv.org/html/2102.09690), methods/content-free-input ablations; [ICCD, Peng et al., ACL 2025](https://arxiv.org/html/2502.13738v2), mapping-contrast objective and negative construction; [HEAL, September 2026 preprint](https://arxiv.org/html/2609.09206v1), head-level counterfactual interaction/calibration, theoretical-scope appendix and limitations; [DeCo, ICLR 2025](https://arxiv.org/html/2410.11779), intermediate-layer correction; [Self-Aug](https://arxiv.org/html/2510.13315), adaptive candidate filtering and contrast failure assumptions. These establish substantial prior art. They do not establish our output-level calibrated mapping contrast as novel or effective for historical handwriting. HEAL's representation-space decomposition is not an exact probability-based PID estimator.

**Critical assessment, 17 October:** contrastive decoding is logically applicable to OCR because it compares image-conditioned probabilities over a shared output vocabulary; it does not contrast the semantic meanings of finished strings or require contrastive training. Text output does not imply language-only computation. However, mathematical validity is weaker than evidence that a reference exposes a correctable recognition error. The four-condition objective is an exploratory hypothesis, not yet a full established research contribution. Its interaction is operational and intervention-dependent; a blank query can induce refusal or an altered task state rather than reveal a pure language prior. Reference subtraction may also remove beneficial length/stopping or lexical preferences. Four native conditions add inference cost and can amplify reference errors.

### The closest prior art is a combination, not one paper

Our implemented rule is `zP + α(zP − zM)` at a common answer prefix, using correct versus rotated support images and the unchanged real query in both branches. This is a contrast over *demonstration association*, not a pure language subtraction. [ICCD](https://aclanthology.org/2025.acl-short.77/) already uses incorrect demonstration mappings and this score family. The closest methodological risk is therefore an adaptation of established contrast to native visual sequence recognition, not a wholly new decoder.

[Native handwriting ICL](https://arxiv.org/html/2609.37195v1) already studies context variability across corpora. [Multimodal ICL modality controls](https://arxiv.org/html/2404.15736) already separate several image/text/order effects. [CAMA](https://arxiv.org/html/2505.17097) and [mapping-guided ICL](https://aclanthology.org/2026.acl-long.622.pdf) already intervene on how demonstrations are aligned and used. [DeCoVec](https://arxiv.org/html/2604.11129) rules out treating a logit adaptation vector or coefficient calibration as novel in itself. [Purpose-trained writer adaptation](https://arxiv.org/html/2603.29450) is also relevant, but differs from adapting an unchanged off-the-shelf VLM. These works do not automatically answer our transcription question; together they substantially raise its novelty bar.

### Recommended paper-level goal

**Understand when a small labelled support bank supplies usable recognition information to a frozen VLM, and use that understanding to improve inference-time handwriting transcription.** This is the research problem, not a novelty claim. Keep linguistic context and visual correspondences as possible complementary resources; do not assume language must be suppressed or that a decoder needs to equal fine-tuning.

A provisional framing is **Inference-time adaptation for handwriting OCR: what demonstrations change, and how decoding should use those changes.** The contribution must be the new validated answer and its consequence, not that title or another equation.

Three connected questions keep the project broad enough to matter while retaining a single purpose:

1. **What information is usable?** Does correct image–transcript correspondence provide recognition value beyond transcript conventions, context order and generic context reweighting? Start from our existing controlled bank. Compare the same inputs wherever possible; removing images also changes prompt length/layout and cannot be treated as an exact isolated module intervention. Writer/style matching is a possible later factor only with verified metadata and a reviewed support/query split; it is not currently an established cause of our result.
2. **Where does that information improve a full transcript?** Does contrast help recover from imperfect generated prefixes, rather than improve predictions under perfect prefixes? This is suggested, not proved, by EXP-018/019. A useful follow-up must connect token changes to complete-output correctness, including harmed cases. Image sensitivity alone is insufficient.
3. **Can the finding guide a stable inference rule?** Freeze a simple rule justified by the above evidence, then test whether it improves matched recognition comparisons across handwriting settings and compatible native VLMs. A reference that wins only for one support ordering or a very weak checkpoint does not establish a transferable method. Adaptive weights, extra terms and attention interventions need evidence and relevant baselines, not speculative implementation.

The coherent publication package would be **a controlled finding about support use, an explanation linked to sequence accuracy, and an improvement or clear predictive boundary that transfers**. These are evidence targets; we have not achieved them. A strong empirical paper is possible without inventing a new formula, but routine replications or inconclusive probes alone would not be enough.
